AirAsia Rewards — static PHP/HTML/CSS prototype

Files:
- login.php
- card-list.php
- card-details.php
- card-add.php
- card-update.php
- styles.css

No PHP code, database, authentication, deletion, or saving is implemented.
All pages are HTML documents saved with .php extensions.
Buttons and forms provide front-end navigation only. The sample cards are hardcoded.
The Add Customer and Delete Gift Card destinations are informational placeholders.

To view locally, run in this folder:
  php -S localhost:8000
Then open http://localhost:8000/login.php

You can also preview the markup by renaming a copy of a .php file to .html.
